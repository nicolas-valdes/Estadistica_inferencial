Script 9.10: (continuación del script 9.8) tamaño del efecto y planificación de un estudio con muestras correlacionadas.

Se usa la tabla del ANOVA de medidas repetidas del script 9.8 para calcular el efecto observado. La planificación compara el número de instancias necesarias con ese efecto y con uno menor, manteniendo tres mediciones por instancia.

# Calcular la f de Cohen observada, con la eta cuadrado parcial y las sumas de
# cuadrados de anova_test()
# Guía: Se extrae la fila Algoritmo de la tabla ANOVA. eta2_p compara la variación del
# Guía: efecto con la suma de esa variación y el error correspondiente.
efecto <- anova_cor[["ANOVA"]] |> filter(Effect == "Algoritmo")
eta2_p <- efecto[["SSn"]] / (efecto[["SSn"]] + efecto[["SSd"]])
# Guía: La fórmula convierte la eta cuadrado parcial a f de Cohen para usarla en la
# Guía: planificación.
f_cor <- sqrt(eta2_p / (1 - eta2_p))
cat("f de Cohen observada:", round(f_cor, 3), "\n")
## f de Cohen observada: 0.749
# Planificar otro estudio: instancias para un poder de 0,90, con la esfericidad
# estimada y el efecto observado aquí, o uno más prudente

Script 9.12: (continuación del script 9.11) gráfico de las medias con barras de Tukey.

Se usan las medias de los tres grupos independientes y el error residual del ANOVA para representar gráficamente la comparación de Tukey. Cada punto es la media de un algoritmo y la barra ayuda a comparar la separación entre medias.

# barras que no se traslapan indican una diferencia significativa según Tukey
# Guía: ms_wg es el cuadrado medio residual del ANOVA. qtukey() obtiene el valor crítico de
# Guía: Tukey usando el número de grupos y los grados de libertad residuales.
ms_wg <- anova_ind[["SSd"]] / anova_ind[["DFd"]]
q <- qtukey(1 - alfa_ind, nmeans = nlevels(datos_largos_ind[["Algoritmo"]]),
            df = anova_ind[["DFd"]])
# Guía: Mitad es la semilongitud de la barra. Se calcula con el tamaño de cada grupo y se
# Guía: dibuja a ambos lados de su media. Para la decisión exacta por par se puede
# Guía: consultar la tabla HSD del bloque anterior.
barras <- datos_largos_ind |> group_by(Algoritmo) |>
  summarise(Media = mean(Tiempo), Mitad = q / 2 * sqrt(ms_wg / n()))
# Guía: geom_pointrange() dibuja un punto para la media y un segmento entre Media - Mitad y
# Guía: Media + Mitad.
g2_ind <- ggplot(barras, aes(x = Algoritmo, y = Media)) +
  geom_pointrange(aes(ymin = Media - Mitad, ymax = Media + Mitad),
                  color = "steelblue") +
  labs(y = "Tiempo de ejecución [ms]") + theme_pubr()
print(g2_ind)
